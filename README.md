# Foodie

HTML + CSS + JavaScript only.

## Run
Open `index.html` in a browser.

## Features
- Responsive design
- Mobile navigation
- Search
- Category filtering
- Favorites
- Cart with quantity controls
- LocalStorage cart
- Checkout modal
- Order confirmation
- Loading screen
- Scroll reveal animations

The food images currently use remote Unsplash image URLs. For a fully offline version, replace them with local images inside `assets/images/`.
